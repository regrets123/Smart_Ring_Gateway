# M7083 BLE Runtime Probe Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an ESP32-C3 boot-time diagnostic that queries the M7083 through both Colmi BLE channels and prints complete raw evidence and per-query results to the serial monitor.

**Architecture:** A pure packet/query module constructs requests and classifies response boundaries. A NimBLE client scans for one configured peer, discovers GATT, subscribes, and passes copied notifications to a bounded queue. A probe runner serializes requests, applies timeouts, logs bytes and outcomes, and is selected instead of the existing mock publisher by menuconfig.

**Tech Stack:** ESP-IDF 5.5.2, C++17, NimBLE host, FreeRTOS, CMake host tests, ESP32-C3.

**Spec:** `docs/superpowers/specs/2026-10-01-m7083-ble-probe-design.md`

## Global Constraints

- Default exact advertised name: `M7083_7904`; optional exact BLE address filter.
- Run once per boot; no BLE-derived JSON or MQTT publishing.
- Automatic writes are read requests plus bounded live HR/SpO2 start and stop only.
- Command GATT UUIDs: service `6e40fff0-b5a3-f393-e0a9-e50e24dcca9e`, write `6e400002-b5a3-f393-e0a9-e50e24dcca9e`, notify `6e400003-b5a3-f393-e0a9-e50e24dcca9e`.
- Big Data GATT UUIDs: service `de5bf728-d711-4e47-af26-65e3012a5dc7`, write `de5bf72a-d711-4e47-af26-65e3012a5dc7`, notify `de5bf729-d711-4e47-af26-65e3012a5dc7`.
- Command packet length 16; checksum is sum of bytes 0..14 `& 0xff`. Big Data reads are `bc <id> 01 00 ff 00 ff`.
- Each request and every received notification must be printed as raw hex with channel, length, and probe label. If queue overflow or truncation occurs, print the exact lost count.
- A missing date skips only HR history; steps use ring-relative day offsets. Never set the ring clock during the probe.

## Review Focus

- Duplicate/partial advertisement names: connect only on a complete exact name and optional address match; test the filter in Task 2.
- Ring disconnects during a live measurement: best-effort stop if still connected and mark remaining probes skipped; test session transition in Task 3.
- Split notifications and unrelated notifications: count the right response while logging unmatched packets; test in Task 3.
- Invalid 16-byte checksum or malformed Big Data length: log the bytes and classify the error without reading past buffers; test in Tasks 1 and 3.
- Missing Big Data GATT channel: retain command probes and report two `UNSUPPORTED_CHANNEL` results; test in Task 3.
